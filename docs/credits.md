## LearnHarness

T3Learn is a modified version of [LearnHarness](https://github.com/amosblomqvist/learnharness) by Amos Blomqvist, licensed AGPL-3.0. The teaching engine, the knowledge graph and the practice and review machinery come from it. T3Learn adds the self-updating Mac app, CLI subscription providers, the sidebar icon row and Settled shelf, and the automatic GitHub backup.
